# 微信小程序文档

本目录收录微信小程序开发的学习与参考文档，基于原生框架（WXML / WXSS / JavaScript）编写。

| 文档 | 内容 |

| [02-工程结构与配置](02-project-config.md) | 目录结构、app.json、页面配置、项目配置 |
| [03-WXML 与数据绑定](03-wxml.md) | 模板语法、数据绑定、条件与列表渲染、事件 |

| [06-页面路由与传参](06-navigation.md) | navigateTo / redirectTo / switchTab、页面间传参 |
| [07-自定义组件](07-custom-component.md) | Component 构造器、properties、插槽、组件通信 |

| [09-分包与性能优化](09-optimization.md) | 分包加载、setData 优化、首屏与包体积优化 |

## 环境说明

- 开发工具：微信开发者工具（稳定版 Stable Build）
- 基础库：文档以基础库 3.x 为准，部分 API 标注了最低版本要求
- 语言：原生 JavaScript（ES6+），WXSS 为 CSS 扩展
