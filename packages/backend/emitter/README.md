# @arkmp/emitter

将 L2 四条转换链的产物片段（wxml / wxss / js / json）拼装为小程序四件套 `{ path, content }[]`，统一处理头注释、WXSS 去重、JSON 序列化与尾部换行。

## 所属层

L3 backend（参考 docs/arkui-miniprogram/09-monorepo.md 的分层）

## 依赖

- `@arkmp/runtime`（`workspace:*`）——使用其导出的 `BASE_WXSS` 基础样式，前置到每个页面 WXSS 产物中。

## 导出 API

### `EmittedFile`

```ts
interface EmittedFile {
  path: string;
  content: string;
}
```

一个产物文件：相对路径（如 `index.wxml`）+ 文本内容。

### `EmitInput`

```ts
interface EmitInput {
  wxml: string;
  wxss: string;
  js: string;
  json: Record<string, unknown>;
}
```

四条转换链的产物片段，作为 `emit()` 的输入：

- `wxml`：transform-wxml 产物（应已合并 classMap / inlineStyles）
- `wxss`：transform-wxss 产物（页面类，不含 runtime 基础类）
- `js`：transform-js 产物
- `json`：transform-json 产物（未序列化的配置对象）

### `EmitOptions`

```ts
interface EmitOptions {
  fileName?: string;
  sourcemap?: boolean;
  source?: string;
}
```

- `fileName`：源文件名（如 `index.ets`），产物路径由其派生；缺省 `index.ets`
- `sourcemap`：为 `true` 时额外产出 `<base>.js.map`（v3）并在 js 末尾追加 `//# sourceMappingURL`
- `source`：原始 `.ets` 源码，用于 sourcemap 的 `sourcesContent` 与行映射

### `emit(input: EmitInput, options?: EmitOptions): EmittedFile[]`

纯函数，无文件 I/O。按以下规则拼装四件套：

| 产物 | 处理 |
| --- | --- |
| `<base>.wxml` | 头部加 `<!-- Generated by ArkMP, do not edit -->`（幂等） |
| `<base>.wxss` | 前置 runtime `BASE_WXSS` 基础类，再按「选择器 + 声明体」去重 |
| `<base>.js` | 头部加 `// Generated by ArkMP, do not edit`（幂等；已带则不重复） |
| `<base>.json` | 2 空格缩进序列化 |

`<base>` 由 `options.fileName` 去掉 `.ets` 后缀得到（目录部分保留，如 `pages/Index.ets` → `pages/Index.wxml`）。所有产物恰好以一个 `\n` 结尾；缩进由上游各 transform 产出，emitter 不重排（避免破坏 `{{}}` 内文本）。

`sourcemap: true` 时额外产出 `<base>.js.map`，`sources` 指回 `.ets` 文件名，`sourcesContent` 内嵌原始源码。行映射按「生成行文本 ↔ 源码行文本」内容匹配建立；方法体内未被改写的行可回溯，结构行与经 `__set` 改写的行无映射。

## 用法示例

```ts
import { emit } from '@arkmp/emitter';

const files = emit(
  {
    wxml: '<view class="ark-text">{{ message }}</view>',
    wxss: '.ark-text { font-size: 16px; }',
    js: 'Page({ data: { message: "hello" } });',
    json: { usingComponents: {} },
  },
  {
    fileName: 'pages/Index.ets',
    sourcemap: true,
    source: etsSource,
  },
);

// files: [
//   { path: 'pages/Index.wxml', content: '...' },
//   { path: 'pages/Index.wxss', content: '...' },
//   { path: 'pages/Index.js',   content: '...' },
//   { path: 'pages/Index.js.map', content: '...' },
//   { path: 'pages/Index.json', content: '...' },
// ]
```
